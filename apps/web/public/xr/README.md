# public/xr/

Self-hosted 8th Wall runtime files. **Generated by `npm install` / `npm run copy-xr`** — do not edit by hand.

| Path | Source |
|---|---|
| `engine/` | `@8thwall/engine-binary` (`xr.js`, `xr-slam.js`, chunks) |
| `xrextras/` | `@8thwall/xrextras` |
| `landing-page/` | `@8thwall/landing-page` (unsupported-browser fallback) |

Loaded from the client AR page via script tags. Image targets use `data-preload-chunks="slam"` with `disableWorldTracking: true`.
