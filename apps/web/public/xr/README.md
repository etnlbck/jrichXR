# public/xr/

Self-hosted 8th Wall engine files. **Generated by `npm install` / `npm run copy-xr`** — do not edit by hand.

| Path | Source |
|---|---|
| `engine/` | `@8thwall/engine-binary` (`xr.js`, `xr-slam.js`, chunks) |

Loaded from the client AR page via a script tag. Image targets use `data-preload-chunks="slam"` with `disableWorldTracking: true`.

The engine binary must ship unmodified (see `engine/LICENSE`; attribution lives at `/licenses`). Loading, permission, error and desktop screens are our own components, and canvas sizing is in `lib/xr-canvas.ts`.
